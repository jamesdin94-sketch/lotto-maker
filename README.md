# 로또 조합 메이커 V1.0

기존 연구 코드(전략 격자, Enigma 암호키, AI 코어 번호, FT≥1 영역)를 그대로 이어받아 하나로 합친 프로그램입니다.
전략을 과거 300회로 시뮬레이션하고, 당첨 횟수·당첨금 순위표를 보고, 내가 전략을 고르거나 추천(순위표 1위)을 써서 번호를 뽑습니다.
**한국 로또 6/45**와 **뉴욕 로또 6/59**를 모두 지원합니다. 설치할 패키지가 없고 파이썬만 있으면 됩니다.

> **꼭 읽어 주세요**
> 로또는 매 회 독립이라 한 장의 1등 확률은 어떤 번호든 같습니다(6/45: 1/8,145,060). 순위표 맨 위 전략은 '과거에 운이 좋았던' 전략일 수 있어서,
> 순위를 정한 구간과 따로 떼어 둔 최근 구간(검증 구간)의 성적을 나란히 보여 줍니다. 오락으로, 여유 자금 안에서만 즐기세요.
> 만 19세 미만은 구매할 수 없습니다. 과몰입이 걱정되면 한국도박문제관리센터 1336.

## 1. 파이썬 설치 (처음 한 번만, 윈도우 기준)

1. 인터넷 브라우저에서 **python.org/downloads** 에 들어갑니다.
2. 노란 **Download Python 3.x** 버튼을 눌러 설치 파일을 받습니다. (3.9 이상)
3. 받은 파일을 실행합니다. **첫 화면 맨 아래 `Add python.exe to PATH` 에 반드시 체크**합니다. 빠뜨리면 아래 5번이 안 됩니다.
4. **Install Now** 를 누르고 끝날 때까지 기다린 뒤 Close 를 누릅니다.
5. 확인: 키보드 **윈도우 키 + R** → `cmd` 입력 → 엔터 → 검은 창(CMD)에서 `python --version` 입력 → 엔터. `Python 3.12.x` 처럼 나오면 성공입니다.
   - `'python'은(는) 내부 또는 외부 명령...` 이 나오면 3번 체크를 빠뜨린 것입니다. 다시 설치하면서 체크하세요.

## 2. 실행

1. 이 페이지 위쪽의 초록색 **Code** 버튼 → **Download ZIP** 으로 내려받아 압축을 풀고, 폴더(`lotto-maker-main`)를 **바탕화면**에 둡니다. (안에 `lotto_maker.py` 와 `lotto_history.csv`, `ny_history.csv` 가 있어야 합니다. 안정판 zip 은 오른쪽 **Releases** 에도 있습니다)
2. 폴더 안의 **`실행.bat`** 을 더블클릭합니다. (한글이 깨질 때도 이 방법)
   또는 **윈도우 키 + R** → `cmd` → 엔터 → 아래 두 줄을 한 줄씩 입력합니다.
```
cd %USERPROFILE%\Desktop\lotto-maker-main
python lotto_maker.py
```
3. 맨 처음에 게임을 고릅니다. `1` = 한국 6/45(기본), `2` = 뉴욕 6/59. 바로 한 게임으로 열려면 `python lotto_maker.py --game ny`.
4. 시뮬레이션이 돌아갑니다(1~4분). 끝나면 암호키 신뢰도표와 순위표가 나옵니다. 이번 회차 동안은 결과가 저장되어 다음부터 바로 뜹니다.

## 3. 전략 가족 (순위표 ID 의 첫 글자)

| ID | 가족 | 내용 |
|---|---|---|
| F… | 필터 격자 | 쌍·삼중·핫·콜드·AC·직전 겹침 필터를 섞은 전략(결과가 같은 것은 합침). 삼중≥1 도 포함 |
| E1~E11 | Enigma 암호키 | 직전 당첨번호를 암호키(ROT+1, ROT+2, MIRROR, SUM, DIFF, BONUS, SWAP, GAP, XOR)로 변환해 얻은 코어 번호 중심 조합. E1·E2 는 신뢰도 상위 5개 암호키의 득표 상위 8개를 코어로 씀 |
| A1·A2 | AI 코어 12 | 직전 10회 핫 번호·콜드·강한 쌍으로 점수를 매겨 뽑은 코어 12개 중심 조합 |
| P1~P3 | 풀(25수) | 번호를 25개(조합 177,100개)로 줄인 뒤 그 안에서만 고르는 전략. P3 은 무작위 풀 대조군 |

| 필터 | 뜻 |
|---|---|
| 쌍 / 삼중 | 직전 10회에 함께 나온 적 있는 두 번호 쌍(세 번호 묶음)이 내 6개 번호 안에 몇 개 있나 |
| 핫 / 콜드 | 직전 10회에 2번 이상 나온 번호 수 / 한 번도 안 나온 번호 수 |
| AC | 번호 사이 차이의 종류 수(높을수록 고르게 흩어짐) |
| 겹침 | 직전 당첨번호와 겹치는 번호 수 |

## 4. 화면 읽는 법

```
  ID 전략                                  5등+률    z  장당금 | 검증 5등+률  장당금
  F1 필터 없음(무작위)                      2.39%   0.4    234 |      2.33%    257
  F1028 쌍=1~2 + 핫=0~1 + …                 2.81%   4.0    294 |      2.56%    198
```
- **5등+률**: 장당 3개 이상 맞힌 비율(선택 구간 200회). 무작위 기대는 6/45 에서 약 2.4%, 6/59 에서 약 1.1% 입니다.
- **z**: 무작위 기대보다 표준편차의 몇 배 높은가. 전략이 1,000여 개이면 1등이 3~4쯤 나오는 것은 우연으로 설명됩니다.
- **장당금**: 장당 평균 당첨금(한국만, 3~5등 합). 무작위 기대 약 220원.
- **검증 5등+률**: 순위를 정할 때 쓰지 않은 최근 100회의 성적. 선택 구간 성적이 여기서도 이어지는지가 중요합니다.

## 5. 메뉴

```
[1] 번호 뽑기  [2] 순위표 기준  [3] 최신 당첨번호 받기  [4] 저장한 번호 결과  [5] 암호키 신뢰도  [6] 신호 분석  [7] 주간 분석(금요일)  [8] 25수 풀 분석  [0] 끝내기
```
- **[1] 번호 뽑기**: 순위표 ID(예 `F1029`, `E1`, `A1`, `P1`)를 입력하거나 `r` = 추천(순위표 1위), `c` = 직접 필터 만들기, `p` = 유튜브 등에서 받아 온 25수 풀 안에서만 고르기(원하면 필터 전략과 함께). 장 수, 꼭 넣을 번호, 빼고 싶은 번호를 입력합니다. 저장하면 `my_picks_kr.csv` 와 구매용 `combos_kr_회차.csv` 가 만들어집니다.
- **[2]**: 5등 이상 / 4등 이상 / 장당 당첨금 / 전체 300회 합산 중 정렬 기준을 고릅니다.
- **[3] → [4]**: 추첨(한국: 토요일 저녁 8시 35분) 뒤 [3]으로 최신 당첨번호를 받고 [4]로 저장한 번호의 결과(장수, 평균 맞힘, 당첨금)를 봅니다. 전략별·세부 항목별 표가 `weekly_report_kr.md` 로 저장됩니다.
- **[5] 암호키 신뢰도**: 각 암호키가 직전 회차에서 만든 예측이 다음 회차와 2개 이상 겹친 비율을 무작위 기대와 비교합니다.
- **[6] 신호 분석**: 실제 당첨번호가 각 필터 값에서 무작위 후보보다 많이/적게 나오는지(배수, z)를 보여 줍니다.
- **[7] 주간 분석(금요일에 한 번)**: ① 지난 회차를 그 회차 이전 자료만으로 다시 뽑아 전략별로 채점 ② 추첨 전에 저장한 번호만 채점해 쌓는 미래 성적 누적 ③ 부진 전략 정리(퇴출) ④ 이번 주 추천 번호(전략별 5장, 자동 저장) ⑤ 25수 풀 분석. 결과는 `weekly_kr.json` 과 `ledger_kr.json` 에 남습니다.
- **[8] 25수 풀 분석**: 번호를 25개로 줄이는 방법이 당첨번호를 더 많이 담는지 무작위와 비교합니다.
- 한 줄 명령: `python lotto_maker.py --update` (당첨번호 받기), `--check` (결과 확인), `--weekly` (주간 분석), `--pool` (풀 분석). 뉴욕은 뒤에 `--game ny`.

## 6. 자주 나오는 문제

| 증상 | 해결 |
|---|---|
| `python` 을 찾을 수 없다고 나옴 | 파이썬을 다시 설치하면서 `Add python.exe to PATH` 체크. 또는 `py lotto_maker.py` |
| 한글이 깨져 보임 | `실행.bat` 로 실행하거나 CMD 에서 `chcp 65001` 입력 후 다시 실행 |
| 최신 당첨번호 받기가 실패함 | 인터넷 연결을 확인하고 잠시 뒤 [3] 다시. 공식 사이트가 응답하지 않는 시간일 수 있음 |
| `cd` 가 안 됨 | 폴더를 바탕화면에 두었는지, 폴더 이름이 `lotto-maker-main`(또는 압축을 푼 폴더 이름)인지 확인 |
